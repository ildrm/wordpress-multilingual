# SEO guide

For published singular native objects in a translation group, Multilingual Core emits alternate links only for published target objects and emits `x-default` for the published default equivalent. Missing targets are omitted. Directory URL generation removes an existing supported prefix before adding the requested prefix.

Translated titles/descriptions, archives, sitemaps, breadcrumb integration, JSON-LD, reciprocal health crawling, and adapters for Yoast, Rank Math, SEOPress, and All in One SEO are not implemented in 0.1.0. Avoid enabling another plugin’s multilingual output simultaneously without testing for duplicate tags.
