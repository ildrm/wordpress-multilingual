# WP-CLI reference

`wp multilingual-core language list` prints language ID, tag, locale, native name, enabled state, and default state.

`wp multilingual-core health` verifies all owned tables and exits non-zero if any are missing.

`wp multilingual-core migrate` re-applies the idempotent schema installer and records the current schema version.

Translate, string scan/cleanup, queue, import/export, and cache-flush commands are not implemented in 0.1.0.
